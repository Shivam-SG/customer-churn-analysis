# Customer Churn Analysis

## 📌 Project Overview

This project analyzes customer churn using the IBM Telco Customer Churn Dataset and Microsoft Excel.

The objective is to identify customer segments with higher churn rates and understand factors associated with customer retention.

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Excel Formulas
* Data Visualization

## 📊 Key Insights

* Overall churn rate: **26.54%**
* Month-to-month contract customers have a churn rate of **42.71%**.
* Fiber optic customers have a churn rate of **41.89%**.
* Electronic check users have a churn rate of **45.29%**.
* Customers with 0–12 months of tenure have a churn rate of **47.44%**.
* Month-to-month fiber optic customers have a churn rate of **54.60%**.

## 📁 Project Files

* `Telco_customer_churn.xlsx` – Dataset and Excel analysis
* `Churn Dashboard` – KPI dashboard and charts
* `Key Insights` – Main findings from the analysis

## 🎯 Objective

To explore customer churn patterns and identify customer groups that may require retention-focused strategies.
